# 在线生鲜商城前端说明

## 概述

本模块是在线生鲜商城系统的前端展示层，采用 Flask/Jinja2 服务端渲染 + Bootstrap 样式框架，实现商品浏览、分类筛选、购物车管理等核心功能的前端界面。

## 技术栈

- **模板引擎**：Jinja2（Flask 内置）
- **样式框架**：Bootstrap 5.3.0
- **渲染模式**：服务端渲染（SSR）
- **适配优先**：桌面端优先

## 文件结构

```
shared/frontend/
├── templates/              # Jinja2 模板目录
│   ├── base.html           # 公共布局模板
│   ├── index.html          # 商品首页模板
│   └── cart.html           # 购物车页面模板
├── static/                 # 静态资源目录
│   └── css/
│       └── style.css       # 自定义样式文件
└── 前端说明.md              # 本说明文档
```

## 模板说明

### 1. base.html - 公共布局模板

**功能**：
- 提供页面公共布局框架
- 包含顶部导航栏
- 集成购物车入口（带数量徽章）
- 显示 Flash 消息提示
- 显示低库存预警横幅
- 引入 Bootstrap CSS/JS
- 引入自定义 style.css

**关键代码块**：
- `{% block title %}`：页面标题块
- `{% block content %}`：主内容区域块
- `{% block extra_css %}`：额外样式块
- `{% block extra_js %}`：额外脚本块

**模板变量**：
- `cart_count`：购物车商品总数量（用于徽章显示）
- `alerts`：低库存预警商品列表
- `get_flashed_messages()`：Flask Flash 消息

### 2. index.html - 商品首页模板

**功能**：
- 展示分类筛选导航（全部/蔬菜/水果/肉类/鱼类）
- 展示商品卡片网格
- 显示商品名称、分类、价格、库存、描述
- 提供加入购物车按钮

**分类筛选逻辑**：
- 当前分类通过 `current_category` 变量判断
- 点击分类后高亮对应按钮
- 分类按钮使用 Bootstrap `btn-group` 组件

**商品卡片结构**：
- 商品图片（优先使用 `image_url`，无图片时显示分类图标）
- 商品名称（支持文本截断）
- 分类徽章
- 商品描述（截断显示）
- 价格和库存信息
- 加入购物车按钮（库存为 0 时禁用）

**表单路由**：
- 加入购物车：`POST /cart/add/<product_id>`

**模板变量**：
- `products`：商品列表
- `categories`：分类列表
- `current_category`：当前选中分类（None 表示全部）

### 3. cart.html - 购物车页面模板

**功能**：
- 展示购物车商品列表
- 显示商品名称、单价、数量、小计
- 提供数量修改表单
- 提供删除商品按钮
- 显示购物车总金额
- 空购物车友好提示

**购物车表格结构**：
- 商品信息列（图片 + 名称 + 分类 + 库存）
- 单价列
- 数量修改列（input + 更新按钮）
- 小计列
- 删除操作列

**表单路由**：
- 修改数量：`POST /cart/update/<item_id>`
- 删除商品：`POST /cart/delete/<item_id>`

**模板变量**：
- `cart_items`：购物车商品列表
- `cart_count`：购物车商品总数量
- `cart_total`：购物车总金额

## 样式设计

### style.css - 自定义样式文件

**设计原则**：
- 页面风格清新、生鲜、绿色自然
- 优先使用 Bootstrap 默认组件
- 补充必要的自定义样式
- 桌面端优先，不做移动端适配

**主要样式类**：
- `.product-card`：商品卡片样式（悬停效果）
- `.card-img-top-wrapper`：商品图片容器
- `.placeholder-img`：商品图片占位符
- `.price`：价格样式（红色强调）
- `.stock`：库存样式（颜色根据库存量变化）
- `.alert-warning`：低库存预警横幅样式

**颜色主题**：
- 主色：Bootstrap Success 绿色（#28a745）
- 价格：红色（#dc3545）
- 背景：浅灰色（#f8f9fa）

## 与后端集成

### 模板变量映射

| 前端模板变量 | 后端传入变量 | 说明 |
|-------------|-------------|------|
| `products` | `products` | 商品列表 |
| `categories` | `VALID_CATEGORIES` | 分类列表 |
| `current_category` | `current_category` | 当前分类 |
| `cart_items` | `cart_items` | 购物车商品列表 |
| `cart_count` | `cart_count` | 购物车总数量 |
| `cart_total` | `cart_total` | 购物车总金额 |
| `alerts` | `alerts` | 低库存预警列表 |

### 路由匹配

| 前端表单 action | 后端路由 | 说明 |
|----------------|---------|------|
| `{{ url_for('cart_add', product_id=product.id) }}` | `POST /cart/add/<product_id>` | 加入购物车 |
| `{{ url_for('cart_update', item_id=item.cart_item_id) }}` | `POST /cart/update/<item_id>` | 修改购物车数量 |
| `{{ url_for('cart_delete', item_id=item.cart_item_id) }}` | `POST /cart/delete/<item_id>` | 删除购物车商品 |

### Flash 消息处理

前端使用 `get_flashed_messages(with_categories=true)` 获取 Flash 消息，并根据消息类别显示不同样式的 Alert：
- `success`：绿色提示
- `error`：红色错误提示
- `info`：蓝色信息提示
- `warning`：黄色警告提示

## 功能特性

### 1. 低库存预警显示

- 预警横幅在页面顶部固定显示
- 仅当 `alerts` 列表不为空时显示
- 预警商品以徽章形式展示，包含商品名称、当前库存、预警线
- 用户可关闭预警横幅

### 2. 商品分类筛选

- 分类按钮组样式，当前分类高亮
- 点击分类后页面刷新，仅显示对应分类商品
- 支持分类：全部、蔬菜、水果、肉类、鱼类

### 3. 购物车数量徽章

- 导航栏购物车按钮显示商品数量徽章
- 仅当 `cart_count > 0` 时显示
- 数量实时更新

### 4. 商品库存状态

- 商品卡片显示当前库存数量
- 库存低于阈值时，库存数字显示为警告色（黄色）
- 库存为 0 时，"加入购物车"按钮禁用，显示"库存不足"

### 5. 购物车数量校验

- 购物车页面显示商品当前库存
- 数量修改输入框设置 `max="{{ item.stock }}"` 属性
- 提交时后端校验数量不超过库存

## 注意事项

1. **不实现登录、支付、订单**：购物车页面结算按钮为演示状态，不实现实际功能
2. **桌面端优先**：样式设计以桌面端为主，移动端不做特殊适配
3. **服务端渲染**：所有页面由 Flask 后端渲染，不使用前端框架（Vue/React）
4. **数据一致性**：页面每次加载时重新查询数据库，确保数据实时准确
5. **静态资源路径**：使用 `url_for('static', filename='css/style.css')` 引入静态资源

## 开发建议

1. 优先使用 Bootstrap 内置组件，减少自定义 CSS
2. 保持模板简洁，复杂逻辑放在后端处理
3. 使用 Jinja2 `{% extends %}` 和 `{% block %}` 实现模板继承
4. 使用 `{{ url_for() }}` 生成路由 URL，避免硬编码
5. Flash 消息用于操作反馈，提升用户体验
