## 路由匹配

所有表单 action 严格匹配后端路由：
- `POST /cart/add/<product_id>` - 加入购物车
- `POST /cart/update/<item_id>` - 修改数量
- `POST /cart/delete/<item_id>` - 删除商品

## 模板变量

与后端完全对接的模板变量：
- `products` - 商品列表
- `categories` - 分类列表
- `current_category` - 当前分类
- `cart_items` - 购物车商品列表
- `cart_count` - 购物车总数量
- `cart_total` - 购物车总金额
- `alerts` - 低库存预警列表

## 设计原则

1. 使用 Bootstrap 5.3.0 组件库
2. 使用 Flask/Jinja2 模板语法
3. 桌面端优先，不做移动端适配
4. 页面风格清新、生鲜、绿色自然
5. 不实现登录、支付、订单功能
6. 服务端渲染，不使用前端框架
