# 在线生鲜商城后端说明

## 概述

本模块是在线生鲜商城系统的 Flask 后端，采用 SQLite 数据库 + Jinja2 服务端渲染技术栈，实现商品浏览、分类筛选、购物车管理和低库存预警等核心功能。

## 技术栈

- **框架**：Flask 3.0.0
- **数据库**：SQLite 3
- **模板引擎**：Jinja2（Flask 内置）
- **运行环境**：Python 3.8+

## 文件结构

```
shared/backend/
├── app.py              # Flask 应用主入口，包含所有路由
├── init_db.py          # 数据库初始化脚本

└── static/             # 静态资源目录（由前端智能体补充）

    └── images/
```

## 数据库

数据库文件路径：`项目根目录/fresh_market.db`

数据表：
- **products**：商品表（14 个示例商品，覆盖蔬菜/水果/肉类/鱼类）
- **cart_items**：购物车表（全局单一购物车，无 user_id）

## 核心函数

### get_db_connection()

获取 SQLite 数据库连接，启用外键约束，返回 `sqlite3.Row` 格式的连接对象。使用 Flask `g` 对象管理请求生命周期内的连接。

### get_low_stock_alerts()

查询库存低于阈值的商品列表，按库存量升序排列。返回列表，每个元素为字典，包含 `id`、`name`、`category`、`stock`、`min_stock` 字段。

## 路由说明

| 路由 | 方法 | 说明 | 模板变量 |
|------|------|------|---------|
| `/` | GET | 商品首页，支持 `?category=分类名` 查询参数 | `products`, `categories`, `current_category`, `cart_items`, `cart_total`, `cart_count`, `alerts` |
| `/cart` | GET | 购物车页面 | `cart_items`, `cart_total`, `cart_count`, `alerts` |
| `/cart/add/<product_id>` | POST | 加入购物车，数量+1；重复加购数量累加 | - |
| `/cart/update/<item_id>` | POST | 修改购物车数量，从表单 `quantity` 字段读取数量；数量为 0 时删除记录 | - |
| `/cart/delete/<item_id>` | POST | 删除购物车商品 | - |

## 模板变量说明

所有页面均传入以下公共变量：

- **alerts**：低库存预警商品列表，列表为空时不显示预警横幅
- **cart_items**：购物车明细列表，每项含 `cart_item_id`、`product_id`、`product_name`、`unit_price`、`quantity`、`subtotal`、`stock`、`image_url`、`category`
- **cart_total**：购物车总价（float，保留两位小数）
- **cart_count**：购物车商品总数量

首页额外变量：

- **products**：商品列表
- **categories**：分类列表 `['蔬菜', '水果', '肉类', '鱼类']`
- **current_category**：当前选中分类，全部为 `None`

## 业务规则

1. **购物车不扣减库存**：所有购物车操作仅修改 `cart_items` 表，不修改 `products.stock`
2. **库存上限校验**：加入购物车和修改数量时，校验数量不超过商品库存
3. **分类白名单**：仅支持 `蔬菜`、`水果`、`肉类`、`鱼类` 四种分类
4. **数量为 0 删除**：修改购物车数量为 0 时，自动删除该购物车记录
5. **低库存预警**：`stock < min_stock` 时触发预警，每次页面加载时重新检测

## 启动方法

### 方式一：手动初始化 + 启动

```bash
cd shared/backend
pip install -r requirements.txt
python init_db.py
python app.py
```

### 方式二：直接启动（自动初始化）

```bash
cd shared/backend
pip install -r requirements.txt
python app.py
```

首次启动时若数据库不存在，会自动执行建表和插入示例数据。

启动后访问：`http://localhost:5000`

## 消息提示（Flash）

后端使用 Flask `flash` 传递操作提示，前端模板中可通过 `get_flashed_messages()` 获取。

消息分类：
- **success**：操作成功
- **error**：操作失败/错误
- **info**：提示信息

## 注意事项

1. 模板目录 `templates/` 和静态资源目录 `static/` 已配置好路径，前端智能体只需放入对应文件即可
2. 数据库文件 `fresh_market.db` 在项目根目录，与 `shared/` 平级
3. 由于不实现登录，购物车为全局共享，所有访问者共用同一个购物车
4. `app.secret_key` 为演示用途，生产环境应更换为安全随机值
