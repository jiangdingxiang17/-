### 2. 核心函数

- **`get_db_connection()`** — SQLite 数据库连接管理
  - 使用 Flask `g` 对象管理请求生命周期内的连接
  - 启用外键约束 `PRAGMA foreign_keys = ON`
  - 返回 `sqlite3.Row` 格式，支持字段名访问

- **`get_low_stock_alerts()`** — 低库存检测
  - 查询 `stock < min_stock` 的商品
  - 按库存量升序排列
  - 返回字段：id, name, category, stock, min_stock

### 3. 路由实现

| 路由 | 方法 | 功能 | 模板变量 |
|------|------|------|---------|
| `/` | GET | 商品首页，支持 `?category=分类名` | products, categories, current_category, cart_items, cart_total, cart_count, alerts |
| `/cart` | GET | 购物车页面 | cart_items, cart_total, cart_count, alerts |
| `/cart/add/<product_id>` | POST | 加入购物车，同商品数量累加 | - |
| `/cart/update/<item_id>` | POST | 修改购物车数量，quantity=0 时删除 | - |
| `/cart/delete/<item_id>` | POST | 删除购物车商品 | - |

### 4. 业务规则

1. ✅ **购物车不扣减库存** — 所有操作仅修改 `cart_items` 表，不修改 `products.stock`
2. ✅ **库存上限校验** — 加购和修改数量时校验 `quantity <= stock`
3. ✅ **分类白名单** — 仅支持 `蔬菜、水果、肉类、鱼类` 四种分类
4. ✅ **数量为 0 删除** — 修改数量为 0 时自动删除购物车记录
5. ✅ **每页传入 alerts** — 所有页面渲染时均传入低库存预警数据
6. ✅ **Flash 消息** — 操作结果通过 flash 传递，分类：success/error/info

### 模板变量约定

所有页面公共变量：
- `alerts` — 低库存预警列表（空列表表示无预警）
- `cart_items` — 购物车明细，每项含：cart_item_id, product_id, product_name, unit_price, quantity, subtotal, stock, image_url, category
- `cart_total` — 购物车总价（float，保留两位小数）
- `cart_count` — 购物车商品总数量

首页额外变量：
- `products` — 商品列表
- `categories` — 分类列表 `['蔬菜', '水果', '肉类', '鱼类']`
- `current_category` — 当前选中分类，全部为 None

## 六、常见问题

### Q: 访问页面报 TemplateNotFound 错误？
A: 正常现象，前端模板还没写，等前端智能体补充后即可正常显示。

### Q: 如何重新初始化数据库？
A: 删除 `fresh_market.db` 文件，重启应用或重新运行 `init_db.py`。

### Q: 购物车是全局共享的吗？
A: 是的，因为不做登录系统，所有访问者共用同一个购物车。
